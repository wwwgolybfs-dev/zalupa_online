# Мост к OpenDota через Cloudflare Workers

Воркер `worker.js` — это тонкий транспорт между сайтом и `api.opendota.com`.
Он нужен, потому что прямой путь «домашний канал → OpenDota» медленный:
крупные ответы (матч — это 1–5 МБ) не докачиваются, а из сети Cloudflare
тот же матч приходит за секунды.

Что делает воркер:

- принимает только `matches/{id}`, `request/{id}` и `players/{id}` — открытым
  прокси он не является;
- проксирует тело потоком, ничего не разбирая (на free-плане всего 10 мс CPU,
  поэтому JSON не парсится и не собирается в памяти);
- кеширует GET-ответы на час через Cache API: повторный матч отдаётся из кеша
  датацентра и не тратит лимиты OpenDota;
- отдаёт CORS-заголовки, поэтому сайт с GitHub Pages обращается к нему напрямую;
- поддерживает `?force=1`, чтобы обойти кеш (это использует кнопка «Обновить»).

## Вариант 1. Через панель Cloudflare (без установки чего-либо)

1. [dash.cloudflare.com](https://dash.cloudflare.com) → **Workers & Pages** → **Create** → **Worker**.
2. Имя, например `kto-ruina-bridge` → **Deploy**.
3. **Edit code** → удалить шаблон → вставить содержимое `worker.js` → **Deploy**.
4. Скопировать адрес вида `https://kto-ruina-bridge.<ваш-поддомен>.workers.dev`.

Проверка: открыть `https://<адрес>/health` — должно вернуться
`{"ok":true,"service":"kto-ruina-bridge",...}`.

## Вариант 2. Через Wrangler (CLI)

```bash
npx wrangler deploy            # из папки bridge/
```

Нужен токен Cloudflare с правом **Workers Scripts: Edit**.

## Необязательно: ключ OpenDota

Если получите API-ключ, положите его секретом — воркер добавит его к запросам,
и троттлинг по IP исчезнет:

```bash
npx wrangler secret put OPENDOTA_KEY
```

Ключ останется на стороне Cloudflare и в браузер не попадёт.

## Как подключить к сайту

В `js/app.js` есть константа `BRIDGE`. Укажите там адрес воркера:

```js
const BRIDGE = "https://kto-ruina-bridge.<ваш-поддомен>.workers.dev";
```

Если `BRIDGE` пустой или воркер недоступен, сайт автоматически работает
напрямую с OpenDota — то есть остаётся работоспособным в любом случае.
